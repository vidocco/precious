5 · Shelf

Each template says how big its items are: fixed, read from a field, or set by rules on another field. Hover a spine: it lifts, its neighbours slide apart to make room, and a leaning one straightens up first.

6 · Item page

Always dark. The cover sits on the left with the info box beside it; both the info box fields and the sections below come from the template. Each value shows its source, and a lock marks a value someone edited by hand. Press Delete to see the confirmation.
